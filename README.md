# Canvas

Compare canvas and print sizes against a person.

Lives at **[canvas.42.uy](https://canvas.42.uy)**.

## How it works

Pick the photo and canvas sizes you're considering. The visualization shows them on a square drafting board next to a 170 cm person silhouette, so the real-world scale is obvious — overlap them centered, overlap them in a corner, line them up in a row, or drag each one wherever you want. Add a mat (paspartu) or frame to any selected size to see how the total dimensions change. Switch to the Grouped section to browse every available size clustered by aspect ratio. Every dimension shows both its native unit (cm or inches) and the converted equivalent, and the app is offline-capable once installed to the home screen.
